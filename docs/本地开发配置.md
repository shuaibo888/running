# 燃赛路跑本地开发配置

## 后端开发期配置

当前按项目约定，开发阶段不使用 `RUNNING_*` 环境变量，所需值直接写在配置文件中，方便本地启动和联调：

- MySQL、Redis 和 SMS4J 厂商参数：`back/ruoyi-admin/src/main/resources/application-dev.yml`
- 燃赛账号、微信登录、短信开关/模板和腾讯地图参数：`back/ruoyi-admin/src/main/resources/application.yml`
- 前端接口地址：`front/common/config.js`

当前 MySQL 已明文配置为 `localhost:3306/running`、用户 `root`、密码 `123456`；Redis 使用 `localhost:6379` 且无密码。微信 AppID 已与 `front/manifest.json` 保持一致，开发期身份摘要密钥已设置为固定的 32 位以上字符串。尚未取得的微信 AppSecret、短信厂商密钥/签名/模板及腾讯位置服务 WebService Key 以空值或“待填写”标识保留；对应能力保持关闭或在调用时返回明确配置错误。

微信一键登录同时消费 `uni.login` code 和 `getPhoneNumber` phoneCode，并自动建立手机号主身份，不存在登录后手工绑定手机号的步骤。启用短信登录前，需要在 `application-dev.yml` 填写 SMS4J 厂商参数，并在 `application.yml` 填写模板 ID、将 `running.sms.enabled` 改为 `true`。

测试定位坐标展示不需要把腾讯 Key 写进前端；测试地址解析和城市足迹时，必须在 `application.yml` 填写 `running.tencent-map.webservice-key`。该 Key 需要开启腾讯位置服务 WebService API 权限，且只写后端配置文件。定位页调用 `POST /app/map/reverse-geocode`，因此还需要有效的小程序登录令牌。

上述明文方案只适用于当前本地开发阶段。准备部署前必须把真实密码和密钥从版本库移除并迁回环境变量或密钥管理服务，同时轮换任何曾经提交过的真实密钥。

## 首版业务表导入

后端代码不会自动创建业务表。`20260903_running_v1.sql` 至 `20260904_running_v6.sql` 已在当前本地数据库按顺序执行，现均为不可变迁移，不得修改或重复执行。后续数据库变化必须从 v7 开始按版本顺序只追加执行。全新数据库的完整迁移顺序为：

```text
back/script/sql/running/20260903_running_v1.sql
back/script/sql/running/20260904_running_v2.sql
back/script/sql/running/20260904_running_v3.sql
back/script/sql/running/20260904_running_v4.sql
back/script/sql/running/20260904_running_v5.sql
back/script/sql/running/20260904_running_v6.sql
```

也可以在仓库根目录使用 MySQL 命令行，密码会由终端安全提示输入，不要把密码写进命令：

```powershell
mysql --default-character-set=utf8mb4 -u root -p --database=running --execute="source C:/Users/ASUS/Desktop/running/back/script/sql/running/下一版本.sql"
```

只有实际看到 16 张 `run_*` 业务表、1 张 `run_schema_history` 迁移登记表及各自关键唯一索引，并确认 `run_workout` 存在 `sport_name`、`record_source`、`met_value`、`ranking_eligible` 和四个 `ranking_*` 地区快照字段，才算当前数据库迁移完成。v4 同时为 `run_achievement` 增加 `reward_points`；v5 增加城市/省份排行榜复合索引。

执行下一版迁移前必须先查询：

```sql
SELECT version_no, script_name, checksum_sha256, installed_on
FROM run_schema_history
ORDER BY CAST(SUBSTRING(version_no, 2) AS UNSIGNED);
```

已登记的版本禁止重复执行。v1-v5 的本地文件 SHA-256 必须与表内值一致；v6 是创建登记表的引导迁移，其库内 checksum 留空，库外基线为 `C4BC90970ACDF7C436D1B9939DF2C633EF965C01F8CBA2B4C68E80877678988D`。

## 前端 API 地址

- 微信开发者工具默认使用 `http://127.0.0.1:8080`。
- 真机不能用 `127.0.0.1` 访问电脑，需要把手机和电脑连到同一局域网，并临时设置：

```javascript
uni.setStorageSync('runningApiBaseUrl', 'http://你的电脑局域网IP:8080')
```

- 清除临时覆盖：

```javascript
uni.removeStorageSync('runningApiBaseUrl')
```

- 正式发布前修改 `front/common/config.js` 中的生产地址，并在微信公众平台配置 HTTPS request 合法域名。
- 小程序业务请求统一携带 `clientid: running-miniprogram`；登录成功后会按 Sa-Token 配置携带 `Authorization: Bearer <后端令牌>`。
